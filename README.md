# Acrobat Bookshelf 電子書櫃與專業閱讀編輯系統

仿造 **Adobe Acrobat Pro** 風格打造的高質感「電子書櫃與多重書籤系統」，完整支援 **PDF** 與 **EPUB** 雙格式之流暢閱讀、高亮批註、自由手繪塗鴉、便籤筆記、章節線上編輯與全維度多重書籤管理。

---

## 🌟 核心特色

### 1. 仿 Adobe Acrobat 經典工作台體驗
- **多功能工具列**：
  - 🖐️ **手形工具 (Hand Tool)**：流暢平移閱讀
  - 🔤 **文字選取工具 (Text Selection)**：支援 PDF / EPUB 精準選詞
  - 🖍️ **螢光筆高亮 (Highlight)**：提供 5 種精選高亮配色（金黃、草綠、天藍、粉紅、淡紫）
  - ✏️ **手繪自由畫筆 (Pen Tool)**：支援流暢向量畫筆手寫註記與劃重點
  - 📝 **便籤筆記 (Sticky Note)**：在頁面任意位置放置便籤圖釘，點選即時展開心得
  - 🔍 **縮放與旋轉 (Zoom & Rotate)**：放大、縮小、符合頁寬、90 度順時針旋轉
- **左側經典四抽屜導航面板**：
  - 📑 **目錄大綱 (TOC / Outlines)**：樹狀目錄即時展開與點擊跳轉
  - 📄 **頁面縮圖 (Page Thumbnails)**：PDF 頁面高畫質微縮圖導覽
  - 🔖 **多重書籤管理器 (Multi-Bookmarks)**：色彩篩選、標籤搜尋、卡片預覽
  - 💬 **註解清單 (Comments & Annotations)**：所有劃線與便籤快速定位
  - ✏️ **EPUB 章節線上編輯器**：支援即時編輯 EPUB 內部 HTML/文字並直接儲存回書檔！

---

### 2. 全維度「多重書籤系統」 (Multi-Bookmark System)
打破傳統閱讀器只能標記「單一頁碼」的限制，本系統實現深度多維書籤：
- **🔴 視覺色標 (5 色分類)**：
  - 🔴 **重要核心**：全書主旨、核心公式、關鍵章節
  - 🟡 **待複習考點**：需二次推導、反覆記憶或疑難點
  - 🟢 **精選引用**：優美金句、經典論述、研究佐證
  - 🔵 **備忘心得**：實作靈感、待辦清單、心得備註
  - 🟣 **深度思考**：延伸研究、跨領域反思
- **🏷️ 自訂多標籤 (Multi-Tags)**：每則書籤可添加多個標籤（如 `#架構`, `#重點`, `#公式`），支援即時過濾與標籤搜尋。
- **📜 引文自動摘錄 (Quote Excerpt)**：滑鼠選取文章段落後按下書籤，自動帶入該段文字作為引文。
- **📝 讀書筆記與心得 (Notes)**：記錄當下的深入想法。
- **📥 一鍵匯出讀書筆記 (Markdown)**：自動將該書所有的多重書籤、引文與心得彙整成結構化 Markdown 文件，無縫串接 Obsidian、Notion 或 Logseq。
- **🌐 全書庫跨書多重書籤索引**：在首頁書櫃隨時點選「多重書籤總覽」，一覽所有書籍的精選筆記並一鍵直達跳轉！

---

### 3. 電子書櫃管理 (Bookshelf System)
- **拖曳匯入**：直接將本地 `.pdf` 或 `.epub` 檔案拖入視窗即可自動解析入庫。
- **自動提取元資料**：自動使用 PyMuPDF 與 EbookLib 解析書名、作者、頁數/章節數並生成高畫質書籍封面。
- **即時搜尋與格式篩選**：支援即時搜尋書名/作者/標籤，並可切換「全部 / PDF / EPUB」。
- **閱讀進度記憶**：自動記錄最後閱讀頁碼與進度百分比。

---

### 4. 線上小說抓取庫與 Z-Library 全球電子書庫 (Novel Downloader & Z-Lib)
- **多站點智慧適配**：支援「Z-Library (zh.z-lib.by)」、「愛下電子書 (ixdzs.tw)」、「筆趣閣 (Biquge)」、「稷下書院 (Novel543)」、「提莫書屋 (Timotxt)」與「PO18 臉紅心跳」。
- **Z-Library 全球書庫支援**：
  - 免費即時搜尋：支援免登入透過行動 eapi 即時檢索全網數百萬本中外書籍與論文。
  - **下載授權與雙模式**：
    - **推薦模式一（帳號一鍵登入）**：點選右上角「Z-Lib 設定」，直接輸入 Z-Library 的 Email 與密碼，系統自動登入官方 API 並儲存專屬金鑰與個人高速節點。
    - **模式二（手動金鑰）**：支援貼上瀏覽器 Cookie 中的 `remix_user_key` 與 `remix_userid`。
    - **免帳號網頁直達**：未登入時下載會彈出引導，並提供「瀏覽器開啟下載頁」按鈕，直達書籍頁面點擊下載，下載後拖入書櫃同樣全自動無損轉為繁體中文！
- **站點熱門榜單探索**：進入「小說抓取」頁面即可直接瀏覽各站點首頁熱門推薦、分類排行榜小說（支援玄幻、都市、言情、仙俠等維度過濾）。
- **關鍵字搜尋與網址解析**：支援跨站書名搜尋，或直接貼上目錄網址/書號即時解析書籍資訊與前 15 章目錄。
- **全自動簡體轉台灣繁體中文 (OpenCC s2tw)**：
  - **自動轉繁體**：凡是抓取或匯入的 EPUB 檔案，只要經演算法判定為簡體中文，系統將自動無損解開 EPUB，將全書章節 HTML、目錄大綱及中繼資料全量轉換為標準台灣繁體中文（並保留所有插圖與 CSS 格式）。
  - **手動一鍵轉繁體**：書櫃卡片右上角或閱讀器工具列均提供「繁」按鈕，可隨時手動觸發一鍵全量轉為繁體中文！
- **排版淨化與防爬修復**：自動過濾廣告標籤、還原韓文象形防爬混淆字元。
- **抓完直接進書櫃**：多執行緒平行下載完成後，自動打包為內嵌封面與 CSS 樣式的標準 EPUB 電子書，自動加入書櫃，可直接無縫點擊閱讀！

---

### 5. 全自動追更系統 (Auto-Update Tracker)
- **已下載線上小說追蹤架**：在「檢查更新」頁面一目了然目前所有線上下載的小說、來源站點、已下載章數與最新章節名稱。
- **一鍵自動檢查更新**：按「檢查更新」即時連線源站比對章節數，若發現新章節將亮起醒目標籤（如：`有 15 個新章節！`）。
- **極速增量更新**：按下「立即更新」，歷史舊章節直接秒讀本地快取（零重複請求），僅抓取最新章節並自動重新封裝最新版 EPUB 覆蓋書庫！

---

### 6. 免開發環境可攜版與原生桌面視窗體驗 (Standalone & Desktop App)
- **免安裝開發環境**：已完整封裝 Python 3.14 核心執行環境、Uvicorn 高效能伺服器、OpenCC 離線繁簡轉換詞庫與 PDF/EPUB 解析核心，未安裝 Python 的全新電腦解壓即可直接雙擊執行！
- **原生桌面視窗模式 (Edge App Mode)**：啟動時優先調用無邊框、無網址列、無分頁之獨立桌面視窗模式，帶來純粹的原生軟體閱讀體驗。
- **閱讀設定永久記憶 (Dual-layer Persistence)**：支援自訂字體縮放（70%~220%）、多款繁體中文字型切換、字體加粗/特粗及閱讀背景主題，關閉程式後雙層持久化永久記憶，再次開啟無縫恢復。
- **精準翻頁與滑鼠滾輪支援 (Mouse Wheel Paging)**：支援滑鼠滾輪向上/向下翻頁（內建 280ms 防暴衝防抖），並徹底修復底層邊界計算，確保章節末頁必定完整展示，杜絕誤跳章節。
- **專屬設計圖示**：配置全套多解析度 Windows ICO、Web Favicon 與 Manifest 向量級書本專屬圖示。

## 🚀 快速啟動方式

### 方法一：Windows 雙擊一鍵啟動（推薦）
在檔案總管中，直接雙擊執行：
```bat
start_bookshelf.cmd
```
或直接執行免安裝可攜版主程式：
```
AcrobatBookshelf.exe
```

### 方法二：命令列啟動
```powershell
cd e:\AI_project\acrobat_bookshelf
python start_bookshelf.py
```

## ⌨️ 常用快捷鍵與操作
| 操作 / 快捷鍵 | 功能 |
|---|---|
| `滑鼠滾輪 (向下/向上)` | 下一頁 / 上一頁 (內建 280ms 防暴衝節流) |
| `← / →` 或 `↑ / ↓` | 上一頁 / 下一頁 (具備單頁邊界防跳章保護) |
| `空白鍵 (Space)` | 下一頁 (`Shift + Space` 為上一頁) |
| `Ctrl + B` | 快速開啟「新增多重書籤」彈窗（自動帶入反白文字與當前頁面） |
| `Enter` | 標籤輸入框按 Enter 即可快速添加標籤 |
